# STEM modules

Optional modules. `on` = files active; `off` = archived here under `<name>/files/`, not loaded, still findable. Details: `<name>/MODULE.md`. Switch: `python3 scripts/module.py list|enable NAME|disable NAME`.

- ux-designer: on - UX/UI designer agent for mockups, UI reviews and implementable design specs
- market-analysis: on - Lean market check before building: alternatives, comparison, build/adapt/use recommendation
- tron: on - Tron mode: build one approved milestone unattended with runner, gate and independent evaluator
