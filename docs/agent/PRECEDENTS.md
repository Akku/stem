# Precedents (Tron mode)

Rulings that came from the user: a sweep answer or a correction of an assumption while reading a report. Sessions search this file and `DECISION_FRAME.md` before they record an assumption. One entry per line, at most 60 lines; drop the oldest or merge when full. The runner and the agent never edit this file during a run.

Format: `P-<n> | <date> | <kind of question> | <ruling> | <source: sweep SWEEP-<milestone> Q<n> or report <run>>`
